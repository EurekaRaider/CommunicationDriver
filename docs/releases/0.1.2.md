Six independent communication modules with a compatible public API.

- Separate TCP, UDP, Serial, SSH, ADB, and CLI directories, configuration headers, backend classes, and implementations.
- Separate scheduling, response processing, platform helpers, and C ABI adapters.
- C consumers need only `communicationdriver.h`; C++23 consumers need only `communicationdriver.hpp`, together with the platform libraries and runtime dependencies.
- Organize C# APIs and contracts by responsibility; apply consistent formatting across all C, C++, and C# sources, headers, examples, and tests, with CI checks.
- Update the README architecture diagram and source navigation.

Downloads:

- Native ZIPs: Windows x86/x64, Linux x64/ARM64, macOS x64/ARM64. Each includes public headers, native libraries, runtime dependencies, licenses, and agent guidance.
- `CommunicationDriver.0.1.2.nupkg`: net48/net10.0 bindings and all six native runtime targets. Use a local NuGet feed.
- `CommunicationDriver-Skill-0.1.2.zip`: standalone agent guidance.
- `SHA256SUMS`: checksums of the eight downloadable packages.

Validation includes six-platform CI and independent package consumers. The architecture refactor also passed local ASan/UBSan/TSan, OpenSSH/SFTP, concurrent load tests, and a 600-second dual-ADB hardware run. Physical serial hardware and overnight loads remain unverified. Performance comparisons apply to the measured host and workloads; see the repository validation report for the complete scope.
